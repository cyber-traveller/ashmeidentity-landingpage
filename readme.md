# Ashme Identity: Landing Page

A responsive landing page for an online coaching and courses business, built in plain HTML with Tailwind CSS from a Figma design.

## Sections

Hero, featured courses, "why choose us", top coaches and a newsletter sign-up.

## Run it

No build step. Open `index.html` in a browser. Tailwind CSS 2.2.19 is loaded from a CDN.
